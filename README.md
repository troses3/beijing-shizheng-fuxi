# 🏛️ 北京时政市情复习系统 (2026京考冲刺)

基于《导氮公基｜2026年北京时政市情手册》（62页全量权威资料）与《政治理论复习》最新工程架构构建的高效刷题与复习系统。

## 🌟 核心特色与功能

1. **三大刷题特训模式**：
   - 🎯 **挖空特训**：精准挖出核心数据、战略定位、专有名词，四选一真题单选，支持点击看官方原文与错题定位。
   - 💡 **易混辨析**：针对易混概念（如“四个中心”与“四个服务”、“两区”与“两重两新”、“三山五园”与“三条文化带”）进行精准对照辨析。
   - ⚡ **速览速记**：全量考点清单流，支持一键遮罩考点词/一键揭晓，适合考前快速冲刺过筛。
2. **顶层架构升级（左右护法布局）**：
   - 🔄 **左上角**：一键重置当前学习进度（安全二次确认）。
   - 🏛️ **中间**：沉浸式状态胶囊，直观展示当前章节与进度 `(1/78)`，点击可展开抽屉面板切换考点专题或查看已掌握/模糊/生词状态。
   - 🔍 **右上角**：全局考点原句搜索，关键词即时过滤并标红高亮，支持独立查看详情，不打乱主刷题指针。
3. **底部悬浮药丸导航栏 (Floating Mode Bar)**：
   - 常驻屏幕底部，适配 iOS `env(safe-area-inset-bottom)` 安全距离。
   - 一键无缝切换：挖空特训 / 易混辨析 / 速览速记 / 顺序 / 随机。
4. **JS 像素级视觉绝对对称居中算法**：
   - 彻底解决 iOS WebKit 弹性盒居中 Bug，动态测量 Header 底部与悬浮条顶部之间的真实视觉留白，实现数学意义上的上下居中。
5. **多端触觉震动反馈 (Haptics Engine)**：
   - 适配 iOS（WebKit Switch Hack）与 Android（Vibration API），选项点击、切题、翻转、标记均有清脆反馈。
6. **轻量化持久存储 (LocalStorage)**：
   - 自动保存已掌握/模糊/生词标记与当前进度，刷新或重启浏览器无缝继续。
